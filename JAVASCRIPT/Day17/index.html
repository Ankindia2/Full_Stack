1. JavaScript Execution Model

  • JavaScript ka code kaise execute hota hai
  • Single-threaded + synchronous language
  • Event Loop async behavior handle karta hai

2. Single-Threaded JavaScript

  • JavaScript ke paas sirf ek Call Stack hota hai
  • Ek time pe sirf ek task execute hota hai
  • Isliye ise single-threaded kehte hain

3. Call Stack

  • Function execution track karta hai
  • LIFO (Last In First Out) follow karta hai
  • Synchronous code yahin execute hota hai

4. Synchronous Execution

  • Code line by line execute hota hai
  • Next line tab chalegi jab current complete ho
  • Heavy loop page ko block kar deta hai

5. Asynchronous JavaScript

  • Time lene wale kaam async hote hain
  • UI block hone se bachta hai
  • Examples: setTimeout, fetch, events

6. Web APIs

  • Browser provide karta hai
  • setTimeout, DOM events, HTTP requests
  • JavaScript engine se bahar kaam hota hai

7. Task Queues

  • Async callbacks yahan wait karte hain
  • Event loop yahin se tasks uthata hai

Microtask Queue

  • High priority queue
  • Promises (.then, .catch)
  • Macrotask se pehle execute hoti hai

Macrotask Queue

  • Low priority queue
  • setTimeout, setInterval
  • Microtask ke baad execute hoti hai

8. Event Loop

  • Call stack ko continuously check karta hai
  • Agar stack empty ho to queue se task uthata hai
  • Execution order manage karta hai

9. Execution Order Rule

  • Pehle synchronous code
  • Phir microtask queue
  • Uske baad macrotask queue

10. Important Interview Points

  • JavaScript single-threaded hai
  • Async behavior Web APIs ki wajah se possible hai
  • Event Loop execution order control karta hai

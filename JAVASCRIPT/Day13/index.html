1. DOM Kya Hai?

  • DOM = Document Object Model
  • HTML ko JavaScript objects me convert karta hai
  • Page ko dynamic banata hai
  • Tree structure me hota hai

2. window vs document

  • window = Browser
  • document = Web page (HTML)
  • document → window ke andar hota hai

3. Element Select Karna

Old Methods

  • getElementById()
  • getElementsByClassName()
  • getElementsByTagName()

Modern (Best)

  • querySelector() → first match
  • querySelectorAll() → all matches

4. DOM Traversing

  • Parent → parentElement
  • Children → children
  • Next → nextElementSibling
  • Previous → previousElementSibling

5. Content Change

  • innerHTML → HTML bhi daal sakte (❌ Unsafe)
  • textContent → Sirf text (✅ Safe)
  • innerText → CSS depend karta (Slow)

👉 BEST: textContent

6. XSS Attack

  • innerHTML se hacker JS inject kar sakta
  • Security risk
  • Solution → textContent use karo

7. Attributes

  • getAttribute()
  • setAttribute()
  • id
  • className

8. classList (IMPORTANT)

  • classList.add()
  • classList.remove()
  • classList.toggle()

👉 CSS handle karne ka BEST way

9. Inline Style

  • element.style.color = "red"
  • Small changes ke liye
  • Large styling ke liye ❌ (CSS + class better)

10. Create Element

  • document.createElement()

11. Add Element

  • append()
  • prepend()
  • appendChild() (old)

12. Remove Element

  • element.remove()

13. DocumentFragment (Performance)

  • Multiple elements fast add karne ke liye
  • Reflow kam hota hai
  • Page fast rehta hai

14. Reflow & Repaint

  • Reflow = Layout recalc (Heavy)
  • Repaint = Color/visual redraw
  • Zyada DOM changes = Slow website

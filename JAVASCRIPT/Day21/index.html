JavaScript Prototype & Class (With Code Examples)

1. Prototype Example (Constructor Function)

  • JavaScript prototype-based language hai
  • Methods prototype me add karne se memory save hoti hai

Code:

function Student(name, age) {
  this.name = name;
  this.age = age;
}

Student.prototype.greet = function () {
  return "Hello " + this.name;
};

const s1 = new Student("Ankit", 20);
const s2 = new Student("Rahul", 21);

console.log(s1.greet());
console.log(s2.greet());

Output:

Hello Ankit
Hello Rahul

2. Prototype Chain Example

  • Property object me nahi mile to prototype me search hota hai
  • Ye process prototype chain kehlata hai

Code:

const obj = {
  name: "Ankit"
};

console.log(obj.toString());

Explanation:

  • toString() obj me nahi hai
  • JavaScript ne Object.prototype me search kiya

3. __proto__ vs prototype

  • prototype constructor function ka hota hai
  • __proto__ object ka reference hota hai

Code:

function Person(name) {
  this.name = name;
}

const p1 = new Person("Ankit");

console.log(p1.__proto__ === Person.prototype);

Output:

true

4. Class Example (ES6)

  • Class ES6 feature hai
  • Class sirf syntax sugar hai
  • Internally prototype hi use hota hai

Code:

class Student {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  greet() {
    return "Hello " + this.name;
  }
}

const s3 = new Student("Ankit", 20);
console.log(s3.greet());

Output:

Hello Ankit

5. Inheritance using Prototype

  • Old JavaScript me inheritance prototype se hoti thi

Code:

function Person(name) {
  this.name = name;
}

Person.prototype.sayHello = function () {
  return "Hello " + this.name;
};

function Student(name, roll) {
  Person.call(this, name);
  this.roll = roll;
}

Student.prototype = Object.create(Person.prototype);

const st1 = new Student("Ankit", 101);
console.log(st1.sayHello());

Output:

Hello Ankit

6. Inheritance using Class

  • extends keyword use hota hai
  • super() parent constructor call karta hai

Code:

class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    return "Hello " + this.name;
  }
}

class Student extends Person {
  constructor(name, roll) {
    super(name);
    this.roll = roll;
  }
}

const st2 = new Student("Ankit", 102);
console.log(st2.greet());

Output:

Hello Ankit

Prototype is a mechanism in JavaScript that allows objects to inherit properties from other objects.
